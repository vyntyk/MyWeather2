# План миграции проекта MyWeather на Clean MVVM + Kotlin + Jetpack Compose

## Обзор

**Цель:** Модернизация Android-приложения погоды до современных стандартов Android 15 без разрушения существующих 11 тестов.

**Стратегия:** Четыре последовательных этапа с сохранением обратной совместимости.

---

2. **Использовать StateFlow для UI состояний:**
   ```kotlin
   data class WeatherUiState(
       val weather: WeatherResponse? = null,
       val geo: GeoLocation? = null,
       val isLoading: Boolean = false,
       val error: String? = null
   )
   ```

3. **Все ViewModel должны использовать `viewModelScope`:**
   ```kotlin
   init {
       viewModelScope.launch {
           weatherRepository.fetchWeatherByCoords(...)
       }
   }
   
   override fun onCleared() {
       // Автоматическая отмена всех запущенных задач
   }
   ```

4. **Подписка во фрагментах через `viewLifecycleOwner.repeatOnLifecycle`:**
   ```kotlin
   viewLifecycleOwner.repeatOnLifecycle(Lifecycle.State.STARTED) {
       viewModel.uiState.collect { state ->
           // Обновить UI
       }
   }
   ```

## Риски и Mitigation

| Риск | Описание | Mitigation |
|------|----------|------------|
| **Break Tests** | Изменение API ломает тесты | Сохранить старые модели, создать адаптеры |
| **Memory Leaks** | Утечки при миграции на Coroutines | Использовать `viewModelScope`, `repeatOnLifecycle` |
| **Compose Migration** | Сложность миграции MapLibre | Оставить MapLibre View, создать Compose wrapper |
